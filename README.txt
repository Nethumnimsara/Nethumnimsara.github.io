NETHUM STATIC PORTFOLIO

Pure HTML + CSS + JavaScript. No React, npm or build step is required.

LOCAL:
1. Extract the ZIP.
2. Open index.html directly, or use VS Code Live Server.

INFINITYFREE:
Upload the CONTENTS of this static-site folder into htdocs:
- index.html
- style.css
- script.js
- assets/

The site includes the supplied profile photo, favicon and FlexGen project images.
External brand logos use Simple Icons CDN; internet access is required for those logos and the Google Maps embed.
